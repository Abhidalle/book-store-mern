# BOOK STORE MERN APPLICATION

This Book Store would allow you to act as your one place stop for managing your library or even your personal books. There can be multiple Creative ways to use this for example you can keep in adding all of the books that you read and then save those as a life counter. Also you can also use this for keeping the track of all the books in an library. This is built using a popular Full Stack Framework knows as the MERN Stack.

# The Tech Stack

## Frontend: React( Using Vite ), Tailwind CSS for styling and React ROuter DOM for page navigation

## Backend: Node.js, Express.js ( with Express Router ), Mongoose ( for database schemas ), and CORS ( for security and privacy reasons).

## Database: MongoDB Atlas ( Cloud Database and free to use by all)

# The Features
The backend is easily fully equipped for CRUD operations being:

1. Create new book entries.

2. Read/Display a list of all books or details of a single book from one place

3. Update existing book information.

4. Delete books from the database.

# Prerequisites
If you will pull this code and try to run this in your computer you need to have tehse pre installed for the basic functioning of this project:

1. Node.js
2. A MongoDB account and their own database URL
